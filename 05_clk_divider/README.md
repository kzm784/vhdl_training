# 05_clk_divider

## モジュール名
`clk_divider`

## 目的
入力クロックを分周して、低周波のクロックを生成する。

クロック分周は FPGA や CPU 制御でよく使われる基本回路であり、カウンタと比較による信号生成の練習に適している。

## 入出力ポート

```vhdl
entity CLK_DIVIDER is
    port (
        CLK        : in  std_logic;
        RST_N      : in  std_logic;
        I_DIV_RATIO: in  std_logic_vector(7 downto 0);
        O_CLK_DIV  : out std_logic
    );
end entity;
```

## ポートの役割

- `CLK` : 入力クロック
- `RST_N` : リセット
- `I_DIV_RATIO` : 分周比を指定する信号
- `O_CLK_DIV` : 分周後のクロック出力

## 動作仕様

1. `rst_n = '0'` のとき `clk_div` を '0' にリセットする。
2. `div_ratio` で分周比を指定する。
3. 分周比ごとに内部カウンタを増やし、閾値に達したとき `clk_div` を反転または立ち上げる。
4. 例: `div_ratio = 2` なら元クロックの 1/2 周期
5. 出力クロックは元クロックの入力パルスに対して擬似的な低速クロックを生成する

## 実装上の注意

- 一番簡単な実装はカウンタを使って `div_ratio` の半分のタイミングで `clk_div` を反転する方法である。
- 分周比が 1 の場合はそのまま入力クロックを渡してもよい。
- `div_ratio` が 0 になると無効なので、仕様上は 1 以上を想定するとよい。
- この回路は出力の周波数を落とすため、タイミング設計には注意が必要である。

## 確認用入力例

### 例1: 分周比 2

- `clk` : 10 MHz
- `div_ratio = "00000010"`

期待値:

```text
clk_div は clk の半分の周波数を持つ
```

### 例2: 分周比 4

- `div_ratio = "00000100"`

期待値:

```text
clk_div は clk の 1/4 周波数を持つ
```

## 実装の目安

クロック分周は、状態遷移の基本と時間制御の理解につながる。

システム全体の動作を遅くするために使われるので、実用的な設計感覚を養うのに適している。
