# 11_sequence_detector_1011

## モジュール名
`SEQUENCE_DETECTOR_1011`

## 目的
入力される1ビットのデータ列から、特定のビット列 `1011` を検出する有限状態機械を設計する。

入力されたビット列の途中一致を状態として保持し、状態遷移によってパターン検出を行う。FSMの状態設計、重なりを許した遷移、1クロック幅の検出パルスを練習する。

## 入出力ポート

```vhdl
entity SEQUENCE_DETECTOR_1011 is
    port (
        CLK      : in  std_logic;
        RST_N    : in  std_logic;
        I_ENABLE : in  std_logic;
        I_DATA   : in  std_logic;
        O_DETECT : out std_logic
    );
end entity;
```

## ポートの役割

- `CLK` : 状態更新用のクロック
- `RST_N` : アクティブLowの非同期リセット
- `I_ENABLE` : '1' のクロックで `I_DATA` を1ビット取り込む
- `I_DATA` : 検出対象となるシリアル入力
- `O_DETECT` : `1011` を検出したクロックの後、1クロックだけ '1' になる

## 検出対象

```text
1 -> 0 -> 1 -> 1
```

## 状態の意味

- `ST_IDLE` : まだ一致していない
- `ST_MATCH_1` : `1` まで一致
- `ST_MATCH_10` : `10` まで一致
- `ST_MATCH_101` : `101` まで一致

`1011` の最後の `1` を受信したら検出成功とし、`O_DETECT` を1クロックだけ '1' にする。

## 状態遷移表

`I_ENABLE = '0'` のときは、入力を取り込まず現在状態を保持する。

| 現在状態 | `I_DATA = 0` | `I_DATA = 1` |
| --- | --- | --- |
| `ST_IDLE` | `ST_IDLE` | `ST_MATCH_1` |
| `ST_MATCH_1` | `ST_MATCH_10` | `ST_MATCH_1` |
| `ST_MATCH_10` | `ST_IDLE` | `ST_MATCH_101` |
| `ST_MATCH_101` | `ST_MATCH_10` | 検出成功後 `ST_MATCH_1` |

`ST_MATCH_101` で `I_DATA = 1` となった場合、`1011`を検出する。同時に、末尾の `1` は次のパターンの先頭にもなり得るため、検出後の状態は `ST_MATCH_1` とする。

## 動作仕様

1. `RST_N = '0'` のとき、状態を `ST_IDLE` にし、`O_DETECT = '0'` にする。
2. `I_ENABLE = '0'` のとき、状態を保持し、`O_DETECT = '0'` にする。
3. `I_ENABLE = '1'` のクロック立ち上がりで、`I_DATA`を1ビット取り込む。
4. `1011` の4ビットが連続して入力されたとき、最後のビットを取り込んだクロックで `O_DETECT = '1'` にする。
5. `O_DETECT` は検出後の1クロックだけ '1' とし、次のクロックで '0' に戻す。
6. パターンの重なりを許可する。例えば `1011011` では、`1011` を2回検出する。
7. `I_ENABLE = '0'` の期間は入力列の途中一致を進めない。

## 確認用入力例

### 例1: 単一検出

```text
I_DATA   : 1 0 1 1 0
O_DETECT : 0 0 0 1 0
```

`I_ENABLE = '1'` が続いている場合、4ビット目の `1` を受信したクロックで検出する。

### 例2: 重なりを含む検出

```text
I_DATA   : 1 0 1 1 0 1 1
O_DETECT : 0 0 0 1 0 0 1
```

入力列 `1011011` の中には `1011` が2回含まれる。

## 実装上の注意

- 状態は列挙型で宣言する。
- 状態レジスタ、次状態論理、出力論理を分けた3プロセス構成を推奨する。
- `O_DETECT` はデフォルトで '0' にし、検出条件だけ '1' にする。
- 検出後に `ST_IDLE` へ戻すと重なりを見落とすため、`ST_MATCH_1` へ遷移する。
- `I_ENABLE = '0'` では、次状態を現在状態にする。

## 実装の目安

まず状態遷移表をそのまま `case` 文へ変換する。その後、検出時の `O_DETECT` の生成方法を考える。

最初はMoore型として、検出成功状態 `ST_DETECT` を追加してもよい。その場合、検出状態を1クロックだけ経由して `ST_MATCH_1` へ戻す構成になる。
