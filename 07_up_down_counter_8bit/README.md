# 07_up_down_counter_8bit

## モジュール名
`up_down_counter_8bit`

## 目的
8 ビットの同期アップダウンカウンタを設計する。

増減方向を切り替えられるカウンタを実装し、方向制御とオーバーフロー処理を学ぶ。

## 入出力ポート

```vhdl
entity UP_DOWN_COUNTER_8BIT is
    port (
        CLK      : in  std_logic;
        RST_N    : in  std_logic;
        I_EN     : in  std_logic;
        I_UP_DOWN: in  std_logic;
        O_COUNT  : out std_logic_vector(7 downto 0)
    );
end entity;
```

## ポートの役割

- `CLK` : クロック
- `RST_N` : リセット
- `I_EN` : カウント有効信号
- `I_UP_DOWN` : 増減方向制御
  - '1' : up
  - '0' : down
- `O_COUNT` : 現在のカウンタ値

## 動作仕様

1. `rst_n = '0'` のとき `count <= "00000000"`。
2. `en = '1'` のとき、クロックで更新を行う。
3. `up_down = '1'` のとき `count` を 1 増加する。
4. `up_down = '0'` のとき `count` を 1 減少する。
5. 0 未満または 255 超えのときは折り返す。
6. `en = '0'` のときは値を保持する。

## 実装上の注意

- `up_down` で分岐し、`count + 1` と `count - 1`を使う。
- 8 ビット数値の上限と下限を管理する。
- `count = "11111111"` の状態でアップすると `"00000000"` に戻る。
- `count = "00000000"` の状態でダウンすると `"11111111"` に戻る。

## 確認用入力例

### 例1: アップ

- `count = 00000000`
- `en = '1'`
- `up_down = '1'`

期待値:

```text
00000000 -> 00000001 -> 00000010 -> ...
```

### 例2: ダウン

- `count = 00000000`
- `up_down = '0'`

期待値:

```text
00000000 -> 11111111 -> 11111110 -> ...
```

## 実装の目安

アップダウンカウンタは、単純なカウントに方向制御を加えた典型的な応用例である。

比較と条件分岐を含む設計として、より実践的な RTL の感覚を養うのに適している。
