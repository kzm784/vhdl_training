# 01_sync_up_counter_4bit

## モジュール名
`sync_up_counter_4bit`

## 目的
4 ビットの同期アップカウンタを設計する。

クロックの立ち上がりエッジごとに 1 ずつ増えるカウンタを実装し、リセットと有効化信号を含む基本的なフリップフロップ駆動の設計を練習する。

## 入出力ポート

```vhdl
entity SYNC_UP_COUNTER_4BIT is
    port (
        CLK    : in  std_logic;
        RST_N  : in  std_logic;
        I_EN   : in  std_logic;
        O_COUNT: out std_logic_vector(3 downto 0)
    );
end entity;
```

## ポートの役割

- `CLK` : システムクロック
  - カウンタの更新タイミングとなる信号
- `RST_N` : リセット信号
  - 低レベル時にカウンタを初期化する
- `I_EN` : カウント有効信号
  - '1' のときだけカウントを進める
- `O_COUNT` : 現在のカウント値
  - 4 ビットの出力

## 動作仕様

1. `rst_n = '0'` のとき、`count` は `"0000"` に戻る。
2. `en = '1'` のとき、クロックの立ち上がりエッジで `count` を 1 増加させる。
3. `en = '0'` のとき、`count` は保持する。
4. `count = 15` の状態で次に増加すると `0` に戻る（オーバーフロー）。
5. すべての更新はクロックの立ち上がりエッジで行う。

## 実装上の注意

- 4 ビットの配列を使って値を管理する。
- `if` 文で `rst_n` を先に判定する。
- `en` が '1' のときだけ `count <= count + 1;` を実行する。
- カウントのラップアラウンドを意識する。

## 確認用入力例

### 例1: リセット

- `rst_n = '0'` で開始
- `clk` が数サイクル進む
- `count` は `0000` に戻る

### 例2: 通常カウント

- `rst_n = '1'`
- `en = '1'`
- `clk` で連続立ち上がり

期待値:

```text
0, 1, 2, 3, 4, 5, ..., 15, 0, 1, ...
```

### 例3: 停止

- `rst_n = '1'`
- `en = '0'`
- `clk` が進んでも `count` は変化しない

## 実装の目安

この問題は、最も基本的な同期型カウンタの設計として扱う。

フリップフロップの状態更新、if 文の順序、レジスタ型変数の扱いを身につけるための初期問題として最適である。
